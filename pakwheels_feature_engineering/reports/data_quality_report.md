## Key findings

- The raw file has 1,874 rows but only 1,001 distinct ads. Each ad was scraped on several dates, and some copies carry a different price. Keeping one copy per ad stops one car from appearing in both the training and test data.
- Price is strongly right-skewed (skewness 5.9 before capping), so its outliers are capped with fences on a log scale.
- Among petrol, diesel and hybrid cars, engine size is clearly linked to price (Spearman 0.43). Only 47% of those cars state the engine size in the name, so the rest are estimated with KNN.
- Electric cars have no engine (0 cc) but a median price of 24.0 million PKR, against 6.1 million for the rest. Across all ads this pulls the engine correlation down to 0.36, so electric cars are kept as a separate fuel group.
- 103 ads have a blank gearbox. 103 are petrol or diesel, 0 are hybrid or electric, 0 mention an automatic gearbox in the name, and 23 say manual. They are coded as Manual. This coding is why `is_automatic` ranks among the most informative features (Spearman 0.44).
- 19 electric models have a blank fuel type. They were recovered from their model names.
- 63 ads have no model year, but every car name ends with one. Where both exist, the name year matches the Model Date column for 100% of ads, so the name year is used.

## Method notes

- Order: parse, remove repeat scrapes, recover facts from text, impute, engineer features, then cap outliers. Features come before capping so that derived columns such as `km_per_year` get the same outlier check as raw columns.
- KNN for engine size uses the model family (first three words of the car name), model year, log mileage and fuel type. Price is never used to fill a feature.
- Price (the target) is capped only when `TREAT_TARGET_OUTLIERS` is True in `src/config.py`.
- Lower-tail flags for mileage and km per year are lightly used or near-new cars. They are capped like every other flag, so their mileage moves up to the lower fence.
- Scaling is left to the model step, because the right choice depends on the algorithm.
